# PantryPilot Monetization Strategy

## Core Principle
Monetization must not gate the core loop. Users must be able to plan meals, manage inventory, and cook confidently on the free tier. Paywalls on essential utility will increase churn for the primary personas.

---

## Recommended Model: Freemium with Monthly/Annual Subscription

### Free Tier
Designed to deliver immediate value and build habit before asking for payment.

| Feature | Free |
|---|---|
| Pantry inventory (up to 50 items) | Yes |
| Meal planner (1 week at a time) | Yes |
| Recipe library (starter set, ~50 recipes) | Yes |
| Guided cooking mode | Yes |
| Shopping list (basic) | Yes |
| Use-soon alerts | Yes |
| Waste reduction nudges (basic) | Yes |
| Household profiles | 1 |
| Ad-supported | Yes (non-intrusive) |

### PantryPilot Plus (Paid Tier)
Monthly: **$4.99/month** | Annual: **$39.99/year** (~33% saving)

| Feature | Plus |
|---|---|
| Unlimited pantry inventory | Yes |
| Multi-week planner | Yes |
| Full recipe library (500+ recipes) | Yes |
| Custom recipe creation and import | Yes |
| Advanced filters (nutrition, macros, budget) | Yes |
| Shopping list export and grocery sync | Yes |
| Household profiles | Up to 6 |
| Waste analytics and history | Yes |
| Ad-free experience | Yes |
| Early access to new features | Yes |

---

## Conversion Strategy

### Trigger Points for Upgrade Prompt
- User hits the 50-item pantry limit
- User tries to access a recipe outside the starter set
- User tries to plan a second week
- User attempts to create a custom recipe
- After 3 successful cooking sessions (high-engagement moment)

### Framing
- Lead with value saved: "You've already avoided wasting 3 items this week."
- Anchor to cost: "Less than a coffee per month."
- Trial offer: 30-day free Plus trial on first prompt (no credit card required)

---

## Secondary Revenue Streams (Post-MVP)

### 1. Grocery Affiliate Partnerships
- Surface sponsored "restock" suggestions linked to grocery delivery partners
- Revenue model: cost-per-click or cost-per-order referral fee
- Risk: must not compromise recommendation neutrality

### 2. Premium Recipe Packs
- Curated recipe collections (e.g., "5-Ingredient Family Meals", "Meal Prep in 1 Hour")
- One-time purchase: $1.99–$4.99 per pack
- Available to both free and paid users

### 3. Nutrition / Dietitian Add-On (Future)
- Personalized nutrition coaching layer
- Separate subscription or one-time consultation fee
- Requires partnership with certified nutrition professionals

---

## Pricing Rationale

| Comparable App | Price |
|---|---|
| Mealime Pro | $5.99/month |
| Paprika Recipe Manager | $4.99 one-time |
| AnyList Complete | $7.99/year |
| Whisk Premium | Free (ad-supported) |

PantryPilot Plus at $4.99/month is competitively positioned. The annual plan at $39.99 encourages commitment and reduces churn.

---

## MVP Monetization Approach
- Launch with free tier only (no ads, no paywall) for the first 90 days
- Focus on activation and habit formation before introducing monetization friction
- Introduce Plus tier and 30-day trial at day 90 once core loop is validated
- Track: free-to-paid conversion rate target of 8–12% within 6 months of Plus launch
