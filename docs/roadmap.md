# PantryPilot 90-Day Roadmap

## Planning Assumptions
- Platform: Mobile app first
- Primary outcomes: faster planning, better cooking confidence, less food waste
- Delivery style: phased releases with short feedback loops

## Phase 1 (Days 1-30): Foundation and Core Flow
### Goals
- Validate core value proposition end-to-end
- Enable first complete user journey: pantry -> plan -> cook

### Deliverables
- Pantry inventory basics (CRUD + expiry fields)
- Recipe model and starter recipe library
- Weekly meal planner baseline
- Guided cooking v1 with per-step timers
- Lightweight onboarding and first-use checklist

### Exit Criteria
- Users can complete first weekly plan and one guided cook session
- Internal test users report clear utility in first week

## Phase 2 (Days 31-60): Recommendation Quality and Retention
### Goals
- Improve recommendation relevance and repeat usage
- Reduce friction in weekly planning and cooking sessions

### Deliverables
- Ingredient-aware recipe recommendations
- "Use soon" and leftover suggestion engine v1
- Favorites, repeat meals, and quick-add plan actions
- Notifications for upcoming expiry and planned meal reminders

### Exit Criteria
- Improved week-over-week active usage
- Increase in planned meals completed per user

## Phase 3 (Days 61-90): Stabilization and Launch Readiness
### Goals
- Prepare MVP for early public rollout
- Strengthen reliability and user trust

### Deliverables
- Data quality improvements for inventory and planner consistency
- In-app feedback collection and issue triage loop
- Performance optimization for core planning and cooking screens
- KPI dashboard for activation, retention, and waste-reduction proxies

### Exit Criteria
- MVP launch checklist complete
- Early cohort shows repeat planning behavior and guided-cook adoption

## KPI Targets for MVP Window
- Activation: user creates first weekly plan by session 2
- Engagement: at least 3 cooking-guide sessions per active week
- Value: downward trend in near-expiry ingredient waste over 4 weeks
